## Cross-repo gotchas

- **The PopMonster site exists in three different forms across three repos.** Edits in one do **not** propagate to the others — always confirm which copy the user means before editing:
  1. **Authoring source = production** — `popmonster-vip` (this repo; lowercase filenames `a001.html`–`a041.html`, deployed to **GitHub Pages** on `popmonster.vip`. Cloudflare Pages also builds this repo at `popmonster-vip.pages.dev` but is only used for PR previews.)
  2. **Zip artifact** — `popmonster-website-deployment/popmonster-pages.zip` (uppercase: `A001.html`–`A031.html`, deployed to GitHub Pages)
  3. **Embedded copy** — `customer-project-portal/client/public/index.html` plus pages generated by `customer-project-portal/server/generate-static-html.mjs`, served at `/`
- **Product page numbering has gaps.** In this repo, `aXXX.html` is non-sequential (deleted SKUs: a011, a014–a016, a018, a019, a021–a023, a025–a029). Always check `README.md` for the canonical list before assuming a file exists.
- **GitHub MCP access is scoped to exactly these five repos.** Calls targeting any other repo are denied. Don't try to fork, clone, or reference repos outside this list.
- **All five repos currently share the feature branch `claude/add-claude-documentation-68Wrh`** for in-flight documentation work. Per-repo branch policies (which branch is `main`-equivalent, what gates production) live in each repo's `CLAUDE.md`.

## Shared conventions

- **End-user language**: Traditional Chinese, Taiwan locale (`zh-Hant-TW`). Brand-facing copy in code is also Traditional Chinese.
- **Brands**: **POP MONSTER / 泡泡怪獸** (parent), **MISO / 米速** (polishing compounds), **SANWU / 叁無** (ceramic coatings). All three appear together in `customer-project-portal` catalog and `popmonster-linebot/products.py`.
- **Build/test/lint commands are repo-specific** — see each repo's `CLAUDE.md` after `cd`. Don't run package-manager commands at the workspace level.
