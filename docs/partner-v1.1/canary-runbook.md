# 單店 LINE AI Canary Runbook

狀態：`DRAFT / 未授權不得執行`

這份 runbook 只準備測試方法，不授權建立資源、放入 secrets、改 webhook 或傳送真實顧客訊息。

## A. 啟動前證據

- [ ] 店家書面授權與資料處理條款。
- [ ] 律師核准資料角色、保存期限與事件通知。
- [ ] 每店獨立 Worker、KV、D1、路由、告警與秘密別名。
- [ ] 原 webhook URL 的受控備份索引（不寫 token）。
- [ ] 監控責任人、測試時段、停止條件與店家聯絡方式。
- [ ] 只使用合成測試資料，不使用真實顧客對話。

## B. 必測案例

| 測試 | 輸入 | 預期 |
|---|---|---|
| 簽章正確 | 合成且有效的 webhook | 接受一次 |
| 簽章缺失／錯誤 | 無效簽章 | 401／拒絕，不寫入資料 |
| 重放 | 相同 event ID | 只處理一次 |
| 缺 secrets | 移除測試環境綁定 | fail closed，不啟動回覆 |
| 價格 | 詢問價目例外 | 轉真人，不自行報價 |
| 退款 | 提出退款 | 轉真人，不承諾結果 |
| 客訴 | 負面事件 | 立即轉真人與標記優先級 |
| 不確定答案 | 知識庫無答案 | 承認不確定並轉真人 |
| 店 A 查店 B | 跨店查詢字串 | 0 筆、0 洩漏、觸發告警 |
| 中央事件 | 模擬對話 | 只見匿名計數，不含 PII |

## C. 分段放量

1. **Dry run**：本機／測試環境，只用合成事件。
2. **Shadow**：接收測試事件但不對外回覆，人工比較預期答案。
3. **Canary**：限定測試帳號與時段，所有輸出先由真人確認。
4. **Limited live**：只有律師、店家與 POP 負責人書面核准後，才可另案執行。

每段都要記錄測試數、錯誤數、人工修正數、延遲、跨店命中與停止決策。未達 0 個硬線錯誤不得進下一段。

## D. 回退原 webhook

只有取得店家授權的人可操作正式環境：

1. 將 LINE webhook 切回事前記錄且已核准的原 URL。
2. 關閉該店 AI Worker 的對外路由或功能旗標。
3. 用合成事件確認簽章、人工接手與回覆路徑恢復。
4. 確認新端點不再收到事件；保留最少必要時間戳與狀態碼。
5. 依保存政策清除 canary 資料並完成事件紀錄。

若原 URL 未經事前驗證、權限不足或任何 secret 狀態不明，不得猜測或切換；保持關閉並交由店家管理者處理。
