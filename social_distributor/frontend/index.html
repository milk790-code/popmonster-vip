Distribute（一鍵分發到人設群組）

      

        把一篇帖文分發到一個或多個「人設群組」。系統會自動：替每個帳號挑選
        對應比例的影片版本、依群組 style 產生不同口吻變體、把多帳號發布時間
        在 jitter 視窗內錯開。
      

      

        
        
        
        
        
        
        
        
        
        
      

      


      
A/B 測試分發

      

        把同一篇帖文在同一個群組內做 A/B 測試 — 偶數帳號走引擎 A，奇數帳號走引擎 B，
        之後在 Insights 頁面查看哪個引擎互動率更高。
      

      

        
        
        
        
        
        
        
        
      

      

    


    

      
人設群組（Account Groups）

      

        把一個 FB / IG / TikTok / YouTube 綁成一組「人設」，每組獨立風格。
        分發時選群組即可一次發到該人設下所有平台。

內容重發（從舊帳號到新人設）

      

        從一個已連接帳號的歷史貼文中挑要重新發布的，自動建立 Post 草稿，
        然後走標準的 Distribute 流程到新人設群組。注意：影片素材是平台
        CDN 短連結，建議在最後送出前重新上傳一份新版素材以避免來源連結失效。

🌐 瀏覽器發布（補 API 接不到的平台）

      

        這層用瀏覽器自動化補官方 API 覆蓋不到的平台。中控台只負責產生「發布指令包
        JSON」，交給 Cowork（全自動）或 Claude in Chrome（半人工）消費；內容中樞仍是
        本中控台。指令包帶 untrusted_page_content 旗標（防注入）與
        idempotency_key（防重複發文）。🔴 平台由風險閘擋下，不產生全自動包。
        最後送出鍵一律由本人拍板。
