# 首頁分享預覽圖：泡泡怪獸商標版（2026-09-28）

## 用途
popmonster.vip 首頁（以及 404、隱私、條款、AI 百科、錯誤回報、免費指南六頁）的
`og:image`／`twitter:image`。在 FB、LINE、Threads、iMessage 貼網址時跳出來的那張圖。

換掉的是 `og-image-1200x630.png`：那張是別的品牌「3Q貢丸」的圖，不是泡泡怪獸。

## 用哪一版商標
金羽毛＋水滴＋金環＋「泡泡怪獸」四字那版（蝦皮天使塗層 Guard 賣場頭貼、38 個 FB 粉專頭貼同一張）。
來源：Drive `02-泡泡怪獸與POP/天使塗層 Guard｜蝦皮賣場素材｜2026-07-18/01-avatar-500x500.png`，
留底在 `src/logo-avatar-500-source.png`。

不用彩色圓形「POP MONSTER 泡泡怪兽 From China」那版：2026-08-12 已經把 FB 粉專上的那版全部換掉，
理由是台灣車主看到 From China 會直接跳走。

## 觀看尺寸
- 100%：1200×630
- FB 手機動態：約 500px 寬
- LINE 聊天泡泡：約 240px 寬（商標要一眼認得出來，四個字看不清可以接受，標題文字會另外顯示在圖下）

## 構圖
- 底色 `#0a0a0a`（品牌手冊 PURE BLACK，不是 `#000`）
- 商標整顆置中，本體（羽毛＋水滴＋金環＋四字）約 470px 高；以本體中心對齊畫面中心，往上偏 6px 做光學置中
- 商標原圖是純黑底＋1px 金褐邊框：裁掉邊框，用 `screen` 疊上底色，四周不可看到方形邊界
- 左下角「POP MONSTER」香檳金 `#c8a96b`、大字距；右下角「popmonster.vip」象牙白 `#e8e2d6` 半透明。兩者距邊 ≥ 56px
- 其他一律不放

## 禁區
- 不放 From China 版商標、不重描、不改色、不給商標加光暈或描邊
- 商標只做兩件事：放大 1.237 倍（500px 是手上最大的原檔）＋輕微銳化（UnsharpMask 1.2／35%／2），都寫在 `src/render.py`
- 不放標語、數字、emoji、QR（這張圖本身就是連回官網的預覽，出口是網址本身）
- 不放任何 3Q貢丸 的東西

## 驗收
1. 1200×630，JPEG ＜ 200 KB（沿用 `tests/test_go_v4.py` 對分享卡的上限）；舊網址 `og-image-1200x630.png` 也換成同一張（PNG）
2. 商標四周沒有方框、沒有色階斷層；100% 放大看羽毛紋理、水滴高光、四個字邊緣乾淨，沒有壓縮方塊
3. 縮到 500px 與 240px 寬，商標一眼可認
4. 商標上下留白差 ≤ 16px（光學置中）；角落小字不碰邊
5. 合併上線後：`curl` 首頁拿到的 `og:image` 指向新圖，新圖回 200

## 為什麼 main 上首頁的 twitter:image 先不改
PR #77 改了首頁 `twitter:title`／`twitter:description`，就在 `twitter:image` 正上方。
main 這邊如果也改 `twitter:image`，兩邊變成相鄰改動，合併會衝突。
所以 main 只改 `og:image`（FB、LINE、Threads 看這個），`twitter:image` 留舊網址——
舊網址的檔案內容已經換成同一張商標圖。#77 合併時會一起把它改成新網址。
